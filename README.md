
# Nostra - Fashion E-Commerce Website

## About the Project
Nostra is a simple and responsive fashion e-commerce website developed using HTML, CSS, and JavaScript. It provides users with an attractive shopping interface to explore fashion collections and products.

## Features
- Responsive navigation bar
- Automatic hero image slider
- Next and previous slider controls
- New Arrivals product carousel
- Most Wanted product carousel
- Product search functionality
- Category-based product filtering
- Newsletter subscription popup
- Contact form with confirmation popup
- Responsive website design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Visual Studio Code

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the website using Live Server or your browser.
5. Explore the different pages and features.

## Website Pages

- **Home:** Displays the hero slider, New Arrivals and Most Wanted products.
- **Collections:** Displays products with search and category filtering.
- **Contact Us:** Allows users to enter their details and submit a message.
